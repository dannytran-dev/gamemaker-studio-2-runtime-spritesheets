# Runtime Sprite Sheets: web demo

Live HTML5 build of the demo: https://dannytran-dev.github.io/gamemaker-studio-2-runtime-spritesheets/

Source code and documentation are on the [main branch](https://github.com/dannytran-dev/gamemaker-studio-2-runtime-spritesheets).

This branch only holds the exported build. To update it, export the HTML5 target from GameMaker and copy `index.html`, `favicon.ico` and `html5game/` into the branch root.
